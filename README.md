# Beeline

Beeline is a Georgia Tech campus-navigation app for iPhone.

Search for buildings, rooms, classes, and campus places. The app can show walking directions, help with room locations, and display live Stinger bus information.

## Features

- Campus, room, course, and place search
- Walking directions around campus
- Room and floor information
- Class schedule support
- Live bus arrivals and locations
- Study-room availability

Most campus data is included with the app. Live bus and study-room information needs an internet connection.

## Run it

Open `Beeline.xcodeproj` in Xcode 16 or later and run it on an iPhone simulator or device.

To build and run the tests from the command line:

```bash
swift build
swift test
```
